NZL component set

Every building block the new site will use, built once and shared by every page. Each component shows where it comes from, which Squarespace element replaces it, and any flag. Copy shown is taken from the approved homepage and the welcome emails, as examples only. Grey boxes are image placeholders.

This is a starting kit, not a fixed list. The foundations (colours, type, spacing, buttons) are fixed. Components will be added or adapted as each page's content needs them, using the same foundations, and shown for approval as they come up.

F5Spacing and layoutSourceCharis, 13 Nov New · grid from the Figma homepage ExistingRuleOnly three section spacings, used above and below every section (header and footer excluded). All values rounded up to the nearest 10px.
Small · 40px desktop · 20px mobile
Sub-sections (for example the trust row under a line) and the gap between stacked blocks
Medium · 80px desktop · 40px mobile
Standard sections
Large · 120px desktop · 60px mobile
Major colour sections (for example Investment pathways)
Card padding · 20px on all sides
Space inside every card before its content starts (pathway cards, article cards)

Rule: every padding, margin and gap is a multiple of 10px.

Layout grid: 7 columns, 40px gutters, fluid to any screen width (4 columns on mobile).

Copy edge: all page copy starts 90px from the page edge (20px on mobile). Colour blocks sit 40px in, with 50px padding inside.

Header and footer: 40px from the page edge, not tied to the copy edge.
